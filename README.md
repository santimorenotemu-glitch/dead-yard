# Dead Yard — Zombie Survival
Juego web 3D experimental para GitHub Pages. Requiere conexión a internet para cargar Three.js desde CDN.

## Publicar
1. Sube `index.html` a la raíz de tu repositorio.
2. Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save.
3. Abre la URL de GitHub Pages.

## Controles
- Móvil: joystick izquierdo para moverse; arrastra el lado derecho para mirar.
- DISPARAR, RECARGA, SALTAR.
- Acércate a la caja y pulsa CAJA para comprar un arma aleatoria por 950 puntos.
- PC: WASD/flechas, R recargar, E comprar, espacio saltar y botón DISPARAR.
